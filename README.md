# 禄波｜商业摄影作品集

一份无需构建工具的响应式静态网站。入口：`index.html`。

## 网站结构

首页以 1MORE 户外耳机影像建立视觉识别，随后按五个拍摄子合集浏览：

1. **品牌智能硬件**：1MORE 耳机、哲轮科技 E-Bike、JBL 音箱、VR 体验设备
2. **场景与生活方式**：户外电源使用情境、宠物旅行季
3. **宠物影像**：猫背带、宠物旅行季

合集封面是大幅图像，下面有子项目卡片，可直接跳到相应项目详情。每个详情采用一张主图加三张辅助图的完整网格；桌面端填满两列构图，手机端排成 2×2。文字区将创作思路、拍摄职责和成果分列对齐；职责和成果仍保留待补标记。

视觉系统采用酒红 `#642d35`、暖象牙白 `#f4efe7`、深可可 `#2a2022` 与香槟金 `#d8c7a2`。酒红负责品牌识别，香槟金只用于细小编号与描边；大面积留白与深色区块建立精品画册般的节奏。

## 本地查看与部署

双击 `index.html` 可在浏览器打开。部署时，把整个文件夹上传到任意静态网站托管服务，默认首页设为 `index.html`。不要拆开 `assets/`、`styles.css` 与 `script.js`，也请保留它们之间的相对路径。

网站没有构建步骤，也没有第三方 JavaScript 依赖。图片经压缩后放在 `assets/`；首屏图优先加载，其余作品图按需加载。尾页联系按钮会打开默认邮件程序的新邮件草稿，并预填主题与简短正文。图片可点击放大，支持方向键切换与 `Esc` 关闭。移动端导航可展开；页面提供键盘焦点样式，并尊重系统“减少动态效果”设置。

## 替换图片

1. 将新图片放入 `assets/`，推荐 JPG 或 WebP，最长边约 1600–2000 px。
2. 在 `index.html` 搜索 `assets/bike-05.jpg` 等文件名，替换 `src` 和 `data-image`。
3. 同步更新图片的 `alt`、放大按钮的 `aria-label` 和 `data-caption`。
4. 更新合集卡片、项目详情与合集数量。当前图片预览会自动读取 `.gallery-image` 按钮，无需单独改 JavaScript。

## 修改文案与发布前待办

页面文字都在 `index.html`。搜索 `[` 可找到待补内容，主要包括项目年份、实际拍摄职责、真实成果、主要求职岗位和常用器材/软件。

两版简历的教育经历不一致，网站暂未展示教育信息；请确认采用哪个版本后再补入。交付量、项目数量和团队信息来自优化简历，发布前请确认统计范围以及个人与团队的职责归属。网站展示了简历中的电话和邮箱，请确认是否愿意公开。

还需确认所有照片的公开与使用权限、项目名称和客户信息是否可见。项目介绍中的创作思路是基于当前成片整理的初稿，请按你的实际方案校准。若希望提供 PDF 简历下载，请把 PDF 放入项目目录，并在联系区增加下载链接。












## 本地编辑模式

在本地浏览器打开 `index.html`，右下角选择“编辑内容”：点击文字可直接修改，拖动图片文件到图片区域可替换，编辑模式下在图片上右键可移除。文字和图片修改保存在当前浏览器的本地存储中；“导出备份”可生成可迁移的 JSON 修改记录，“导入备份”可恢复记录。该模式仅在 `file://` 本地页面或 localhost 显示，不会向公开访客开放。

本地浏览器保存不会自动改写网站源文件或同步到线上。要正式发布，需要将替换图片放入 `assets/` 并更新 HTML，或接入带登录验证的 CMS；前端编辑器本身不具备服务器账号权限。

## 独立部署（脱离豆包平台）

本站是纯静态网站，不依赖任何平台、无需服务器和构建步骤，可部署到任意静态托管服务。

**最简方式（GitHub Pages）**
1. 在 GitHub 新建仓库，把本文件夹内容上传（index.html 需在仓库根目录）。
2. 仓库 Settings → Pages → Build and deployment → 选 Deploy from a branch → 选择 main 分支根目录。
3. 几分钟后即可通过 `https://<你的用户名>.github.io/<仓库名>/` 访问。

**Vercel / Netlify（无需 GitHub 经验）**
- 注册 Vercel 或 Netlify 后，选择「导入现有项目 / Deploy manually」，直接把本文件夹拖入即可上线，自动获得 https 链接。

**自己的服务器 / 云存储**
- 把整个文件夹放到 Web 根目录（如 Nginx 的 html 目录、对象存储桶），默认首页是 index.html，保持 assets 相对路径不变即可。

部署后即可把链接放进简历或投递邮件。线上公开版本不含本地编辑模式（仅 file:// 或 localhost 可见），访客只能浏览。
